ส่วนที่ 5

เทรนยังไง แล้ววัดว่า "ใช้ได้จริง" ยังไง

  1. เทรนแบบผสม 2 ปี — ตามที่ตกลงกัน: โมเดลตัวจริงเรียนจากทุกแถวที่มีคำตอบ (ปี 68 เต็มซีซัน + ปี 69 ถึงเดือนล่าสุด) เพื่อให้ปรับตัวเข้ากับรุ่นปัจจุบัน
  2. วัดผลแบบเดินตามเวลา (expanding window) — ห้ามสุ่มแบ่ง เพราะจะแอบเห็นอนาคต ตัวเลขสวยเกินจริง:
    รอบวัดเรียนจากสอบกับ
    1ปี 68 ทั้งปี69 เม.ย.
    2ปี 68 + 69 มี.ค.69 พ.ค.
    3ปี 68 + 69 มี.ค.–เม.ย.69 มิ.ย.
    4ปี 68 + 69 มี.ค.–พ.ค.69 ก.ค.
    แต่ละรอบจำลองสถานการณ์จริง: "ถ้าใช้โมเดลเดือนนั้น จะแม่นแค่ไหน"
  3. ตัวชี้วัดหลัก: precision@30 — ให้โมเดลชี้ 30 คนที่เสี่ยงสุด แล้วนับว่าหลุดจริงกี่คน (เลข 30 = จำนวนที่ mentor โทรตามไหวจริงต่อเดือน)
  4. เกณฑ์ผ่าน — ต้องชนะวิธีปัจจุบัน (tier แดง/ส้มจากการเข้าเรียน) ถ้าไม่ชนะ = ยังไม่ deploy ใช้ลิสต์ผสมไปก่อน

ความคาดหวังที่สมจริง: จากการซ้อมกับข้อมูลจำลอง โมเดลจับได้ ~30% ใน 30 อันดับแรก เทียบ tier เดิม ~23% — ไม่ใช่หมอดู แต่ทำให้ mentor โทรถูกคนบ่อยขึ้นราว 1 ใน 3 · ของจริงต้องรอเทรนจึงรู้ (churn จริงปี 69 สูงถึง 41% — สัญญาณน่าจะชัดกว่าข้อมูลซ้อม)

บท 01 — นิยามปัญหา + สร้าง label✓ ครบแล้ว — label จริง 2 ปีสร้างเสร็จ (นอกสมุด)

เปลี่ยนคำถาม "เด็กคนไหนจะหลุดคอร์ส" ให้เป็นโจทย์ที่คอมพิวเตอร์เรียนรู้ได้ คือ 1 แถวต่อ (นักเรียน, เดือน) พร้อมคำตอบ churned_next_month แล้วลงมือสร้างตาราง label นี้เองจากบันทึกสมัคร/ยกเลิก เพราะระบบเก็บแค่สถานะปัจจุบัน ไม่มีประวัติว่าใครออกเมื่อไหร่

หัวข้อในบท

  1. นิยาม churn ของ EWT ให้เป๊ะ (ยกเลิกหมด vs ลดวิชา)
  2. ทำไมต้องสร้าง label เอง + template ชีตบันทึกยกเลิก (การบ้านจริง)
  3. สนามซ้อม: toy data นักเรียน 6 คน
  4. จากเหตุการณ์สมัคร/ยกเลิก → เดือนที่ active
  5. ติด label แบบ naive แล้วเจอกับดัก censoring
  6. censor เดือนที่ตอบไม่ได้ให้เป็น NaN

บท 03 — EDA: churn หน้าตาเป็นยังไง… รอทำกับข้อมูลจริง (หลังบท 02)

ก่อนยกงานให้โมเดล เราต้องเห็น pattern การหายของนักเรียนด้วยตาตัวเองก่อน — บทนี้พาดูว่าเดือนไหนน้องหายเยอะ จาก 100 คนเหลือกี่คนเมื่อเวลาผ่านไป และพฤติกรรมก่อนหาย (เข้าเรียนน้อย, เงียบหาย) ต่างจากคนที่อยู่ต่อแค่ไหน เพื่อได้ทั้งไอเดีย feature สำหรับบทถัดไปและเรื่องเล่าที่ทีม mentor เชื่อ

  1. churn rate รายเดือน เทียบ 2 ซีซัน (pivot_table)
  2. survival curve — จาก 100 คนเหลือกี่คน (cumprod)
  3. พฤติกรรมก่อนหาย (1): attendance ฟ้องไหม (merge + boxplot)
  4. พฤติกรรมก่อนหาย (2): สัญญาณเงียบหาย silent_weeks (crosstab)
  5. เปิดสนามอิสระ — ตั้งคำถามเองแล้ว groupby หาคำตอบ
  6. สรุป signal ทั้งบท → ว่าที่ feature ของบท 04
